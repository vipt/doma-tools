Doma Tools

Eclipse用プラグインの更新サイトです。このフォークでは、DAOメソッドの呼び出し元から Doma > Jump to SQL File でSQLファイルを開けます。

更新サイトURL
https://vipt.github.io/doma-tools/

  1. Eclipseで ヘルプ → 新規ソフトウェアのインストール… (Help → Install New Software…) を開きます。
  2. 追加… (Add…) を選び、名前を Doma Tools、ロケーションを上記の更新サイトURLにします。
  3. Doma → Doma Tools を選び、内容とライセンスを確認してインストールします。
  4. Eclipseを再起動します。

Eclipse 2023-12 / Java 17の環境を対象にビルド・テストしています。 既存のDoma Toolsと同じプラグインIDを使用するため、既存のインストールを更新します。

以降の更新は ヘルプ → 更新の確認 (Help → Check for Updates) から行えます。 署名や提供元の確認が表示された場合は、表示された内容を確認してください。
