日本語

Eclipse用プラグインの更新サイトです。このフォークでは、DAOメソッドの呼び出し元から Doma > Jump to SQL File でSQLファイルを開けます。

  1. Eclipseで ヘルプ → 新規ソフトウェアのインストール… (Help → Install New Software…) を開きます。
  2. 追加… (Add…) を選び、名前を Doma Tools、ロケーションを上記の更新サイトURLにします。
  3. Doma → Doma Tools を選び、内容とライセンスを確認してインストールします。
  4. Eclipseを再起動します。

Eclipse 2023-12 / Java 17の環境を対象にビルド・テストしています。 既存のDoma Toolsと同じプラグインIDを使用するため、既存のインストールを更新します。

以降の更新は ヘルプ → 更新の確認 (Help → Check for Updates) から行えます。 署名や提供元の確認が表示された場合は、表示された内容を確認してください。

English

This is the Eclipse update site for Doma Tools. This fork lets you open SQL files from DAO method calls using Doma > Jump to SQL File.

  1. In Eclipse, open Help → Install New Software….
  2. Click Add…. Enter Doma Tools as the name and the update site URL above as the location.
  3. Select Doma → Doma Tools, review the installation details and license, then complete the installation.
  4. Restart Eclipse.

The plug-in is built and tested against Eclipse 2023-12 / Java 17. It uses the same plug-in ID as the original Doma Tools, so installing this fork updates an existing Doma Tools installation.

For future updates, use Help → Check for Updates. If Eclipse displays a signature or publisher trust prompt, review the details shown.
